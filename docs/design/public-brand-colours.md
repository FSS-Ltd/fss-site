# Public site colour palette

The FSS public site pairs its existing light surfaces with the founder's warm
black (`#211b17`) and burnt orange (`#b55937`). Dark rust (`#a64224`) is used
for text accents on light backgrounds; light rust (`#e6a07f`) is used on dark
surfaces. Success, warning and error colours keep their existing meanings.

The original FSS navy (`#07182e`), teal (`#14989e`), deep teal (`#0f7078`) and
cyan (`#46c7d8`) remain as supporting accents for navigation, focus, subtle
page decoration and selected motion details. The personal palette remains the
primary colour treatment.

The public palette is scoped to `#fssroot`. Public motion may adopt these
colours, but colour-only edits must preserve animation timing, geometry,
scroll-driven behaviour, reduced-motion handling and interaction hooks.
